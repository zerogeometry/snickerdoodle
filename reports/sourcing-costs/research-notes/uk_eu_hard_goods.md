# UK/EU print-on-demand and dropship makers for hard goods and giftware (Prodigi alternatives)

Research date: 26 November 2026. Every page cited was read (or seen in search results) on 26 Nov 2026 unless a page date is given. Currency: GBP. Conversions use €1 = £0.87 and $1 = £0.79. Ex-VAT figures in brackets are my own division by 1.2 where the site only showed inc-VAT. "Needs account" = the price sits behind a login or a live configurator and I did not sign up.

Scope: 11oz two-tone sublimation mug, flat ceramic ornament ~7.5 cm, 8 cm shatterproof plastic bauble with insert disc, phone cases (slim/snap and tough, iPhone + Samsung), printed faux-leather Apple Watch strap, cork-backed placemats (~28x20 cm, pack of 4), coasters (~10 cm, packs of 2/4/6). Printful EU is covered by another researcher and is mentioned here only as context.

## Which makers make which product types in the UK/EU, and at what trade price and spec

### Takeaway
Inkthreadable (Blackburn, UK) is the only maker found that covers most of the list from one UK site with a documented order API: a two-tone mug (£6.50 inc VAT), a 7.5 cm round ceramic ornament (£5.94), a 28x20 cm cork-backed placemat (£9.76 each) and a 4-pack of cork coasters (£7.64). It has no bauble and no watch strap, and its "phone case" is an aluminium-insert iPhone case, not a snap/tough range. Phone cases are best served by Podbase (Lithuania, EU): snap from about £6.92 and tough from about £8.66 ex shipping. Tradeprint (UK) is a mug option with free UK delivery and an API. No UK/EU dropship maker for a printed Apple Watch strap other than Prodigi itself turned up. No dropship maker for the 8 cm plastic insert bauble turned up either; it exists only as a blank (UK suppliers).

### Inferences

## UK delivery cost (first + extra item, tracked or not; can items ship together)

Tradeprint mugs include free UK mainland delivery. Podbase ships to the UK from Lithuania at "EU region" rates, using first-item plus cheaper additional-item pricing. The exact UK euro figure was not readable.

## API / integration effort

### Takeaway
Inkthreadable, Contrado and Tradeprint each have a real order API, so a custom (non-Shopify) site like Snickerdoodle can integrate directly. Inkthreadable's is a simple signed REST API with no documented webhooks, so status must be polled. Podbase advertises an "Open API" but also mentions an "upcoming API". Printeers and Bags of Love are app-led (Shopify).

### Cited Findings
- Inkthreadable API endpoints: list orders (GET /api/orders.php?AppId=…&Signature=…), filter, get one, count, create and delete (unpaid orders only). Order statuses include received, in progress, paid, refunded, stock allocation, printing and quality control, plus a `deleted` flag. No webhook documentation was found — [Inkthreadable API endpoints](https://help.inkthreadable.co.uk/en/articles/429293-api-request-endpoints); [Inkthreadable creating orders via API](https://help.inkthreadable.co.uk/en/articles/426593-creating-and-processing-orders-through-inkthreadable-s-api); [Inkthreadable API collection](https://help.inkthreadable.co.uk/en/collections/8562487-inkthreadable-s-api)
- Contrado API: create products, upload designs, submit orders, track fulfilment and sync products. Shopify and WooCommerce are live, Etsy is "coming soon". Docs are at api.contrado.app/helix/docs, but that page rendered only a title to my fetcher. Webhooks are not mentioned — [Contrado print-on-demand API](https://au.contrado.com/print-on-demand-api); [Contrado Helix docs](https://api.contrado.app/helix/docs)
- Contrado Shopify app: 4.5 from 47 reviews; "additional charges may apply" (search snippet) — [Contrado Shopify app reviews](https://apps.shopify.com/reviews/789438)
- Tradeprint Connect: REST API + SDK, Postman docs via a sandbox, and a "Development" account requested from sales@tradeprint.co.uk after a discovery call. A credit account is required. No transaction charges, and integration support is free "subject to projected order volumes". Docs: https://docs.sandbox.tradeprint.io/ — [Tradeprint API](https://www.tradeprint.co.uk/tradeprint-api)
- Podbase: Shopify, Etsy, WooCommerce and Order Desk integrations plus an "Open API" integration guide. The page also refers to an "upcoming API solution". No subscriptions or upfront costs. Packaging inserts are offered — [Podbase custom phone cases](https://www.podbase.com/product/custom-phone-cases)
- Bags of Love dropship runs through a Shopify app (one-time sync). No public API docs were found — [Bags of Love FAQ](https://www.bagsoflove.com/faq/228)
- Printeers: Shopify app; orders are picked up automatically — [Printeers Shopify app](https://apps.shopify.com/printeers)

### Inferences
- Integration effort is lowest for Inkthreadable: a small REST client, signature auth and a status poller. Tradeprint needs a sales conversation and a credit account first. Contrado's docs could not be assessed.

### Gaps
- Webhook support at any of these makers; Contrado's API auth and endpoints; whether Podbase's API is generally available (needs account).

## Minimums, fees, trade tiers, branded packaging; data protection headline; in-house option

### Takeaway
None of the shortlisted makers has minimums or subscription fees. Inkthreadable is strictly plain white-label with no inserts, while Podbase sells packaging inserts. All shortlisted production is UK (Inkthreadable, Contrado, Tradeprint) or EU (Podbase, Lithuania), and nothing in the shortlist is made outside the UK/EU. Printify may route outside the UK/EU depending on provider, so it needs checking per product. An in-house sublimation set-up costs roughly £340–£820 to start.

- In-house only pays off at volume and adds labour, packing, breakage and postage handling. It is a possible later route for the bauble and the watch strap, which lack a UK/EU dropship maker other than Prodigi.
